# ⚔️ Dungeon Clicker

**Version 1.0**

一款像素風第一人稱放置點擊遊戲。

每一次鍵盤或滑鼠按下，都會轉化成一次攻擊。
揮動生鏽鐵劍，攻擊巨大史萊姆，隨著點擊次數累積，
挑戰不斷提升的階段。

## 🎮 遊戲特色

- 第一人稱像素風地下城
- 巨大史萊姆階段變色
- 全鍵盤與滑鼠按下皆可攻擊
- 劍擊與受擊動畫
- 支援透明背景與地下城背景切換
- 即時顯示點擊數、階段與 HP
- 無需 API 或外部付費服務
- 完全靜音

## 🚀 建置與啟動

1. 下載或複製專案
2. 執行提供的 `.bat` 建置檔
3. 等待建置完成
4. 開啟產生的遊戲檔案

## 📈 階段成長

每個階段所需點擊數為上一階段的兩倍，
持續向更高階段挑戰。
